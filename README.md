The project is a chatbot assistant for an Agora-type school intranet. The user logs in, asks a question, receives an answer 
based on an internal knowledge base, views documents, and can send an appointment request.
The project is deliberately designed as a stage or demonstration version:

• User accounts are demo accounts.
• Intranet data is stored in JSON files.
• The actual connection to Agora is not included.
• OpenAI API key is configured.
